## Лабораторная работа № 2: Многостраничный web-сайт

**Описание проекта:**
Разработан персональный web-сайт на тему «Мир видеоигр». Проект включает 3 страницы: главную, таблицу с избранными ААА-играми и информацию об авторе.

**Выполнение требований задания:**
* Проект реализован на чистом HTML и CSS. Стили вынесены в отдельный подключаемый файл `style.css`.
* Применены строчные и блочные теги, настроена навигация с помощью ссылок, добавлены изображения.
* Создана таблица. Выравнивание колонок (по левому краю, правому краю и по центру) реализовано средствами CSS.
* Использовано 3 вида CSS-селекторов: по тегу (например, `body`, `table`), по классу (например, `.container`, `.nav-menu`) и псевдокласс состояния (`:hover`).
* Фреймворки и JS не использовались.
